Кириллица в JSON — 27.10.2026

1. Скачать opera_full_module_readable_json.txt.
2. В конфигураторе открыть общий модуль КХ_ОбменШиныОпера и заменить весь текст содержимым файла.
3. Сохранить, проверить синтаксис, обновить конфигурацию базы (F7), перезапустить тестовый сеанс.
4. Проверить новый пакет после обычного изменения товара: name должен содержать читаемую кириллицу.

Изменена только функция ВJSON: ЭкранированиеСимволовJSON.СимволыВнеASCII заменено на ЭкранированиеСимволовJSON.Нет. JSON остаётся стандартным; обязательное экранирование кавычек, обратной косой черты и управляющих символов выполняет штатный сериализатор.
Общая функция используется Opera, PC и справочником СЕ, поэтому новые сообщения всех этих потоков будут с читаемой кириллицей.
Существующие сохранённые пакеты в очереди остаются прежними. Их содержимое и batch_id не переписывать: после разбора JSON бэк получает те же строки.
Отправку, ACK, фильтры товаров и очистку эта правка не меняет. Платформенная проверка новой записи кириллицы выполняется пользователем после установки.
