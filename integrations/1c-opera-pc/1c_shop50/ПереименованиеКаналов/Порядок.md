# План сокращения имён каналов

Пока это план: переименование на Шине, обновление метаданных Астора и миграция очереди ещё не подтверждены. Четыре рабочих общих модуля сборки не переведены на новые имена автоматически.

Причина: исходное имя Opera содержит 58 символов, на скриншоте в записи осталось 50. Ограничение длины измерения требуется проверить в метаданных; его увеличение не восстанавливает усечённые записи.

1. Завершить отладку неудачной отправки и оставить фоновые отправители отключёнными.
2. В проекте Шины переименовать схему ExchangeOpera в Opera, PriceChekerExc в PC, не меняя проект, модуль Основной и группы участников.
3. Opera: сначала ToBackend → ToAstor, затем ToShopsOpera → ToBackend, FromShopsOpera → FromAstor. FromBackend оставить.
4. PC: сначала ToBackendShops → ToAstor, затем ToShops → ToBackend, FromShops → FromAstor, FromBackendShops → FromBackend.
5. Проверить линии: магазины → FromAstor → ToBackend → бэк; бэк → FromBackend → ToAstor → магазины. Типы узлов Канал1СИсточник/Назначение сохраняются.
6. Проверить проект и опубликовать/обновить существующее тестовое приложение. Адрес приложения при переименовании схем не менять. Не создавать второе приложение случайно.
7. В конфигураторе обновить существующий сервис ExchangePriceCheker из опубликованного приложения штатной командой обновления каналов, не удаляя сам сервис и другие сервисы. Название и расположение этой команды зависят от интерфейса конфигуратора. Сверить реальные новые имена.
8. Ожидаемые исходящие имена: Komandor_PriceCheker_Основной_Opera_FromAstor (45 символов), Komandor_PriceCheker_Основной_PC_FromAstor (42). Фактические метаданные имеют приоритет.
9. Заменить только ПараметрыОбмена в КХ_ОбменШиныОпера фрагментом из ПараметрыОбмена_после_переименования.txt, сверив реальные имена каналов. Авторские отметки semidockij добавлены. Для ACK/запросов проверить обработчики новых ToAstor: Opera → КХ_ОбменШиныОпера.ОбработатьВходящееСообщение; PC → КХ_ОбменШиныПрайсЧекеры.ОбработатьВходящееСообщение. Обработчики создавать/проверять через свойства каналов, сохраняя сгенерированную платформой сигнатуру. Выполнить проверку синтаксиса, F7 и перезапустить сеанс.
10. Выполнить ИсправитьКаналТестовогоПакета.txt один раз в серверной консоли. Скрипт предназначен только для указанного пакета, не отправленного из-за неверного имени канала: заменяет ключ в транзакции, сохраняет JSON и batch_id, не затрагивает OperaState. Скрипт не исполнялся на платформе 1С в рабочем пространстве.
11. Запустить тестовую Opera в Шине; проверить код отправителя и тестовых участников. Отправить одну Opera через ОтправитьПорциюПакетов("Opera", 1), затем СервисыИнтеграции.ВыполнитьОбработку(). Проверить ОчередьШины и журнал Шины. Отправлено не равно обработано бэком.
12. Если бэк уже подключён, после переименования ему заново получить реальные channel/destination из API опубликованного приложения. Не составлять AMQP destination из короткого имени вручную.
