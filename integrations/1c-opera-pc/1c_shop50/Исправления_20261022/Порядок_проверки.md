# Найденные несоответствия 22.10.2026

1. На скриншоте метаданных сервиса ExchOperaPC внешний канал задан как `Komandor::PriceCheker::Основной::ExchangeOpera.FromOpera`, тогда как последние скриншоты текущего приложения Opera-PC показывают процесс `Komandor::Opera_PC::Основной::Opera`. Нужно скопировать точное внешнее имя источника магазина из текущей опубликованной схемы (веб-интерфейс, процесс Opera, вкладка Каналы 1С) и сверить/исправить свойство `Имя канала внешнего сервиса интеграции` в метаданных. Если источник по-прежнему FromOpera, ожидаемое имя — `Komandor::Opera_PC::Основной::Opera.FromOpera`, но фактическая публикация имеет приоритет. Аналогично проверить входящий и оба канала ПрайсЧекеров. Внутренние имена метаданных, параметры модуля и очередь не нужно менять, если они уже согласованы, как в присланной версии.
2. В присланной версии модуля немедленно после `ВыполнитьОбработку()` выполнялся `ОстановитьОбработку()`. Он удалён из исполняемого кода с авторским блоком semidockij. Остальной текст присланного модуля сохранён. Это устраняет остановку, способную прервать обмен; сама по себе правка ещё не подтверждает доставку.
3. Заменить только процедуру РегламентнаяОбработкаОчередиОпера текстом из этой папки; либо использовать полный текст ДляКопирования/КХ_ОбменШиныОпера.txt. Выполнить проверку синтаксиса, F7 и перезапуск сеанса.
4. В серверной консоли вызвать КХ_ОбменШиныОпера.ЗапуститьОбработкуСервисовИнтеграции() и проверить доставку уже поставленных сообщений. Если потребуется повторная постановка того же пакета, метод ОтправитьПорциюПакетов("Opera", 1) допускает повтор Sent не раньше чем через 300 секунд после последней попытки. Не менять batch_id и JSON.

Проверено сравнением исходников: изменён только один блок с запуском/остановкой; внутренние имена сервиса и каналов пользователя сохранены; исполняемых вызовов ОстановитьОбработку в исправленном модуле нет. Новый запуск BSL Language Server и проверка на платформе 1С для этой редакции не выполнялись. Ранее приложенный отчёт анализатора относится к прежней редакции. Доставка сообщения не подтверждена.
