# Исправление обращения к Периодичность — 03.11.2026

Пользователь фактически запустил проверку35: в строке20 ошибка «Поле объекта не обнаружено (Периодичность)». Этот неверный доступ был как в сообщении консоли, так и в getter общего модуля. Виновата подготовленная нами реализация; успех офлайн-парсера не проверял наличие API-поля.

Пользователь подтвердил точные метаданные: и в ШтриховыеКоды, и в ОсновныеШтрихкоды есть реквизит ДатаИВремяЗаписи типа Дата с составом Дата и время. Поиск по синониму больше не нужен.

Исправление: в getter после КБЖУ оставлены только:

```bsl
ТаблицаОсновныхШтрихКодов = "РегистрСведений.ОсновныеШтрихкоды";
ИмяПоляДатыШК = "ДатаИВремяЗаписи";
```

Прежний условный блок Периодичность/СрезПоследних для ОсновныеШтрихкоды и цикл поиска поля даты полностью удалены. Затем идёт прежний Запрос = Новый Запрос и Запрос.Текст. Основной код читается прямой связью регистра по Номенклатуре; последняя коробочная запись — по подтверждённому ДатаИВремяЗаписи регистра ШтриховыеКоды. Запросы срезов цен и акций не менялись.

В консольной проверке удалено обращение Метаданные.РегистрыСведений.ОсновныеШтрихкоды.Периодичность из Сообщить. Без исправления модуля удаления одной строки консоли было бы недостаточно.
