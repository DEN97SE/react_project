# Нормализация подтверждённых конфликтов упаковки и повтор пакетов PC

Пользователь подтвердил: правильный вариант спорных ШК — шт/1; дублирование этих кодов на коробках является ошибкой НСИ. Правило дополняет29.10: при наличии подтверждённого штучного варианта он имеет приоритет перед конфликтующей коробкой. Другие корректные коды товара, в том числе основной, сохраняются.

До проверки конфликтов barcodes, отдельно для каждого project/store_id/nomenclature_id/строкового barcode:

1. Проверить, есть ли запись unit=шт с корректным количеством1. Сравнение количества числовое; отсутствие/некорректность не приравнивать к1. Пробелы/регистр названия единицы нормализуются только для проверки шт.
2. При наличии такой записи исключить из обработки этого ШК варианты с другим положительным коэффициентом. Не применять выбор первого элемента: кор/100 или кор/50 стоят раньше шт/1 в двух предоставленных карточках.
3. Полные повторы удалять; остальные коды/поля сохранять. Одинаковый ШК разных товаров этим правилом не объединять. Если шт/1 нет, прежнюю явную проверку неоднозначности не обходить.
4. После нормализации выполнить все обычные проверки и фактическую фиксацию порции. Только затем настоящий ACK processed. Не менять статусы вручную и не подтверждать непринятый пакет.
