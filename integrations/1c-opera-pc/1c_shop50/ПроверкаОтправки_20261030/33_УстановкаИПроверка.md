Два прохода обеспечивают приоритет независимо от порядка: коробка может стоять первой. Приоритет работает для одного товара и одного строкового ШК. Есть шт/1 — конфликтующий положительный коэффициент другой строки не попадает в barcodes. Другие коды, включая основной, и корректные самостоятельные упаковки сохраняются. Нулевой/отсутствующий коэффициент не объявляется единицей; конфликты без подтверждённого варианта шт/1 не выбираются произвольно.

Для проверки открыть **консоль кода** и выполнить33_ПроверитьШтучныеШК_50_410.bsl в50 и410. Она только читает карточки штатным сборщиком, проверяет конкретные ID товаров, отсутствие кор/30, кор/100, кор/50 на повторяющихся кодах и наличие второго штучного кода каждой карточки. В410 ожидается одна строка [ОК], в50 две. Код не отправляет сообщения, не правит НСИ и не ставит новый full.
