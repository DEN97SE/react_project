# История, не установка

Здесь сохранены прежние предложения, тексты и рисунки, чтобы не потерять контекст. **Актуальны `../modules`, `../bus` и `../README.md`. В `../fragments` теперь только пояснение об отсутствии требуемых вставок.**

- V1/V2 содержали отдельные регистры состояния/очереди. Пользователь отказался от их создания.
- Некоторые варианты предполагали транзит справочников через ДО. Актуальный поток идёт из Астора через Шину напрямую в бэкенд.
- Предложенная изменённая копия `Интеграция1СШина` отозвана: этот штатный модуль менять запрещено. Она сохранена только в `withdrawn` для истории и сравнения.
- Старые схемы, подписи готовности и инструкции в этих каталогах могут противоречить последующим решениям. Не применять их к базе.

Сгенерированные ZIP, PDF и HTML-дубликаты не хранятся: исходные тексты, изображения прежних схем и актуальные модули сохранены отдельно.

Вариант `2026-11-04-http-with-queue` отозван 05.11.2026: пользователь запретил вообще обращаться к прикладному регистру очереди. В текущем коде прямая отправка сервисом интеграции, без регистрации и общего перечня исключений.

Позднее 05.11.2026 разрешён существующий регистр с удалением после успеха бэка и TTL 3 суток. Вариант без регистра сохранён в 2026-11-05-direct-without-queue. Новый адаптер повторно использует публичную регистрацию и прямой транспорт; старый HTTP-вариант с оболочкой пакета не восстанавливается целиком.
