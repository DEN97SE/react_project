# История, не установка

Здесь сохранены прежние предложения, тексты и рисунки, чтобы не потерять контекст. **Актуальны только `../modules`, `../fragments` и `../README.md`.**

- V1/V2 содержали отдельные регистры состояния/очереди. Пользователь отказался от их создания.
- Некоторые варианты предполагали транзит справочников через ДО. Актуальный поток идёт из Астора через Шину напрямую в бэкенд.
- Предложенная изменённая копия `Интеграция1СШина` отозвана: этот штатный модуль менять запрещено. Она сохранена только в `withdrawn` для истории и сравнения.
- Старые схемы, подписи готовности и инструкции в этих каталогах могут противоречить последующим решениям. Не применять их к базе.

Сгенерированные ZIP, PDF и HTML-дубликаты не хранятся: исходные тексты, изображения прежних схем и актуальные модули сохранены отдельно.
