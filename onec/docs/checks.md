- PASS static: строки, скобки, блоки и отсутствие повторов методов во всех семи активных BSL-модулях.
- PASS static: межмодульные ссылки и экспорты; известный внешний вызов перечня исключений Opera отмечен отдельно.
- PASS static: из защищённого общего модуля вызывается только предоставленный экспортный ЗарегистрироватьОбъектВОчереди. Его файл не изменялся.
- PASS static: только существующие регистры; новых констант и регистров нет.
- PASS static: единственный низкоуровневый вызов удаления проходит через фабрику менеджера записи с полным ключом всех пяти измерений и проверкой метки/формата.
- PASS static: возврат отправки в Шину не удаляет строку, подтверждение требует applied=true и HTTP 200; дедлайн задаётся один раз и равен 259200 секунд.

- PREPARED, NOT RUN: BSL-тесты границ 72 часов и HTTP-кодов; JSON и ответственные проверяются прежними тестами.
- NOT RUN: компиляция/исполнение 1С и Шины, реальные SQL/права, транзакционные гонки, фильтры собственных отправителей Opera/ПК, привязка HTTP-отчёта/события сервиса, API и безопасные повторы на бэке.

Сценарии чужой строки, раннего/позднего ответа, удаления и перезапуска перечислены в reuse-and-queue-72h.md для исполнения на стенде.
