Выполнен python onec/tools/check_bundle.py. Скрипт структурный, не компилятор 1С/Шины.

- PASS static: строки, скобки, блоки, отсутствие повторов методов в пяти активных BSL-модулях.
- PASS static: межмодульные вызовы разрешены и экспортированы.

- PASS static: прямой отправитель задаёт configuration = Astor; присланный маршрутизатор читает тот же параметр и выбирает Http_kp_Astor.
- PASS static: Authorization сохранён как в рабочем коде, тело устанавливается из потока, оболочка payload/revision отсутствует.
- PASS files: все пять исходных вложений совпадают с прежним манифестом SHA-256.
- PASS files: старые активные модули/фрагменты/схема сохранены в history/2026-11-04-http-with-queue; прежние инструкции не считаются актуальными.
