# Справочные модули ShelfSpace, не код текущего обмена кабинета

Два вложения пользователя от 05.11.2026 просмотрены полностью. Здесь сохранены копии для анализа, исходные файлы остаются во вложениях и локальном каталоге attachments. Имена функций, номера строк и код сохранены; удалены конечные пробелы, окончания строк приведены к LF, BOM не переносится.

В каждом исходнике найден встроенный X-Api-Key в функции обработки изображений. В копии для репозитория только его значение заменено на [REDACTED_API_KEY]. Значения не выводились в отчёт и не отправлялись в Git. Номера строк и контрольные суммы исходников/копий — в manifest.json.

Эти модули выполняют прямой HTTP-обмен со ShelfSpaceCenter. Они не содержат обработчик входящего сообщения сервиса интеграции кабинета. Не устанавливать их вместо КХ_КП_ТранспортШины и не переносить их авторизацию/очередь в кабинет.
