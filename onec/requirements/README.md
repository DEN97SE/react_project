# Исходное ТЗ

DOCX — исходный документ, предоставленный пользователем. `spec-extracted.txt` содержит извлечённый текст для поиска. Имена исходных вложений и их SHA-256 перечислены в `../sources/manifest.json`.

Документ не подменяет последующие решения по реализации. В частности, справочники и ответственные идут напрямую из Астора через Шину в кабинет, транспорт к бэкенду — AMQP 1.0, новых регистров не создаём, штатный `Интеграция1СШина` не меняем.
