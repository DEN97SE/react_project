# Исходное ТЗ

DOCX — исходный документ, предоставленный пользователем. `spec-extracted.txt` содержит извлечённый текст для поиска. Имена исходных вложений и их SHA-256 перечислены в `../sources/manifest.json`.

Документ не подменяет последующие решения по реализации. В частности, справочники и ответственные идут напрямую из Астора через Шину в кабинет, по решению от 04.11.2026 транспорт к бэкенду — HTTP/HTTPS, новых регистров не создаём, штатный `Интеграция1СШина` не меняем.

Уточнение 05.11.2026: новый обмен вообще не обращается к ОчередьШины. Реальная рабочая схема прислана пользователем, использует параметр configuration и Authorization. Входящий KP.GET принимает тело с сайта; polling из ранней интерпретации ТЗ не подменяет этот маршрут. ТЗ остаётся исходным документом, а не подтверждением фактических URL/контрактов.

Последующее решение 05.11.2026 отменило запрет работы с очередью: использовать существующую ОчередьШины, удалять только после подтверждённого успеха бэка, TTL недоставленных 3 суток. Новых регистров/констант и изменений защищённого модуля по-прежнему нет.
